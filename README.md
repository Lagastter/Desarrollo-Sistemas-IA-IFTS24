## Estructura del repositorio

* `notebooks/`: Cuadernos interactivos desarrollados en Deepnote.
  * `002 – Python Repaso - Osorio Brian Joel.ipynb`: Ejercicios de sintaxis, variables, condicionales, listas y bucles.

* **Lenguaje:** Python 3
